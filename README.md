# Excel-Dashboard - Interactive Sales Dashboard

### About:
An interactive Excel dashboard designed to analyze sales performance and provide business insights. Transforms raw sales data into meaningful KPIs, charts and visualizations to help overall business performance.

### Tools Used:
- MS Excel - Pivot Tables, Slicers, VLOOKUP, Conditional Formatting
- Charts - Bar, Line, Donut, KPI Cards

### Key KPIs Tracked:
- Total Sales & Profit
- Sales by Category / Region
- Monthly Performance Trend
- Top Products
